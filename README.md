# 🌍 GlobeTrotr

**Plan the journey. Bring everyone along. Keep the memories.**

A multilingual travel dashboard for solo travellers, groups and travel agencies.

[Website](https://globetrotr.nl) · [Documentation](docs/README.md) · [Licence](LICENSE) · [Security](SECURITY.md)

## ✨ What you can do

| | Possibilities |
| --- | --- |
| 🗺️ Plan | Destinations, routes, transport, maps, activities and daily itineraries. |
| 🎟️ Organise | Bookings and reviewable drafts from forwarded booking confirmations, when configured. |
| 👥 Collaborate | Invitations, travel roles, shared expenses and balances. |
| 📔 Remember | Travel journals, media, summaries and selected public stories. |
| 📱 Take along | Selected offline trip content, calendar feeds and exports. |
| 🧳 Agency | Clients, client portals, quotes, invoices, team permissions and branding. |
| 🛡️ Account | Privacy choices, account security, exports and deletion requests. |

Availability depends on the plan, role and configured providers. Search results
are suggestions, not confirmed bookings. Offline access covers selected content.

## 📚 Source and documentation

This source-viewing edition includes application/worker source, public website
assets and general technical documentation. It excludes private Git history,
internal runbooks, infrastructure configuration, incident reports and planning.
Example node addresses in the access-control helper are documentation addresses,
not live endpoints. This is not a production deployment package.

Built with React, TypeScript, TanStack Start/Router/Query, Vite, Tailwind CSS,
Radix UI, Leaflet and Supabase. See [architecture](docs/ARCHITECTURE.md) and
[development notes](docs/DEVELOPMENT.md).
