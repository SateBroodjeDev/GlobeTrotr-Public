# ✨ Features / Mogelijkheden

## Travel planning

Create and organise trips, destinations, transport and daily activities. Maps,
route calculations and GPX import support itinerary planning. Bookings can be
recorded manually; configured booking-mail import produces drafts for review.

Invite fellow travellers with appropriate roles. Shared expenses and balances
help groups keep track of costs. Travel journals combine text, media and selected
public stories. Selected offline packages, calendar feeds and exports help when
travelling. Connected features may still require an internet connection.

## Agency workspaces

Agency workspaces support teams, clients, client portals, quote workflows,
invoices, branding, tasks and templates. Availability depends on account plans,
permissions and the configured services. The public source does not grant access
to any hosted workspace or customer data.

## Accounts and privacy

Account tools include security settings, communication/privacy preferences,
data exports and deletion requests. Public sharing is separate from private
trip and workspace access. Retention or shared ownership can limit deletion.

## Integrations

The implementation connects to identity, storage, mail, translation, routing,
flight and payment providers. External services require separate setup and
credentials. Search candidates are not confirmed reservations; code and test
availability do not prove a successful real-world provider transaction.

## Nederlands

Plan reizen en routes, bewaar boekingen, werk samen en verdeel uitgaven. Leg
herinneringen vast in het reisdagboek en neem geselecteerde inhoud offline mee.
Agency voegt klanten, offertes, facturen en teambeheer toe. Privacy- en
accountinstellingen blijven gescheiden van openbare deelmogelijkheden.
Abonnementen, rechten en externe configuratie bepalen wat beschikbaar is.
